# Persona

Turn a folder of documents into a searchable static website.

## Features

- DOC/DOCX → PDF
- PPT/PPTX → PDF
- Native PDF support
- Folder browsing
- Automatic navigation
- GitHub Pages compatible
- Built on Docusaurus

## Quick Start

npm install
npm start

Place documents inside `content/`.


This project is built on top of docusaurus.
